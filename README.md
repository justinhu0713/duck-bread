# 鸭鸭抢面包 · Duck Bread

[**在线开玩 / Play now**](https://justinhu0713.github.io/duck-bread/)

你是抢面包的鸭子，还是守池塘的大鹅？在同一张地图上追逐、抢补给、躲天灾。遇到首领时，双方还得暂时放下恩怨，一起打完再继续争夺。

**Duck Bread** is a single-player 2D browser survival game. Play as a bread-stealing duck or a pursuing goose, dodge extreme weather, and team up with the computer-controlled rival when a boss appears.

## 怎么玩

1. **选角色。** 鸭子每捡一块面包得 10 分，活过倒计时或击败大鹅即可赢下普通生存回合。选大鹅时，在倒计时结束前击败鸭子。
2. **选难度。** 普通、困难和地狱模式各有 40 关，进度独立。常规回合的生存倒计时为 120 秒。
3. **看地图和预警。** 从双池塘出发，可以穿越树林、海岸、火山、沙漠和冰川。右上角小地图标出双方位置、避难点和部分天灾。看到落点预警就离开危险区，遇到海啸或风暴可优先找附近的避难点。
4. **首领出现就暂时合作。** 沙虫、章鱼、北极熊或哥斯拉等首领出现时，双方可能进入合作，生存倒计时暂停。第 20、40 关需击败沙虫、章鱼和北极熊，再迎战追加的哥斯拉。

## 操作

| 键位 | 动作 |
| --- | --- |
| 方向键 / WASD | 移动 |
| Shift | 鸭子冲刺；大鹅放捕网 |
| J / K | 霸体 / 鸭子分身 |
| 空格 / R | 射击 / 切换手枪和狙击枪 |
| H / L | 使用法杖 / 投掷药水 |
| M / T | 投掷天灾印记 / 使用瞬移道具 |
| P | 暂停或继续 |

手机可使用画面上的方向按钮和技能按钮。游戏内还可以切换音效或全屏。

## 补给和天灾

- **先找补给。** 血包可回血，满血时通常提高生命上限。跑鞋提供短暂加速。复活道具可在倒下时救场。
- **留意武器和射程。** 手枪和狙击枪各有独立弹药，靠近大炮可发射。药水和法杖能打出不同效果。
- **天灾印记命中后才生效。** 它会开启本关的十种极端天气。风涡追踪实际命中的目标，后续定向落点瞄准该目标附近。海啸、沙尘暴等仍按各自的路线推进，留意屏幕和小地图上的预警。
- **普通流星和巨型陨石是两回事。** 遇到巨型陨石的大红圈要尽早撤离，单靠无敌躲不过撞击。

更详细的伤害、冷却和道具规则可以在游戏页面下方查看。

## 保存与重玩

游戏会自动保存，也可点击「保存进度」手动保存。「继续存档」恢复该难度的最新进度，「读取手动存档」回到手动保存点。失败后可重试当前关卡。已通关的关卡可从主页面选择重玩，重玩进度与主线存档分开。

进度存在当前浏览器的 `localStorage`。线上地址、本地地址和不同浏览器分别保存。清除该网站的数据会移除对应进度。

## 本地运行

克隆仓库后，用浏览器打开 `index.html`。也可用 Python 启动本地服务器，方便在固定地址反复测试。

```bash
git clone https://github.com/justinhu0713/duck-bread.git
cd duck-bread
python3 -m http.server 8000
```

然后访问 [http://localhost:8000/](http://localhost:8000/)。项目使用原生 HTML、CSS 和 JavaScript，无需安装前端依赖，也无需构建。GitHub Pages 从 `main` 分支根目录发布，代码和音效使用相对路径。

## 代码位置

| 文件 | 用途 |
| --- | --- |
| `index.html`、`style.css` | 游戏界面、操作按钮和规则说明 |
| `game.js` | Canvas 绘制、输入、游戏循环和存档界面 |
| `world.js`、`campaign.js` | 地图、镜头和关卡进度 |
| `combat.js`、`factions.js`、`boss-skills.js` | 战斗、道具、阵营和首领技能 |
| `disasters.js`、`desert.js`、`flood.js`、`glacier.js`、`godzilla.js` | 天灾、地形事件与首领逻辑 |
| `audio.js`、`assets/audio/` | 音效播放和本地版使用的 10 个音效 |

绘制时会缓存地形、跳过视野之外的物体，并把雨线合并绘制。电脑角色评估避险路线时会复用风涡预测，减少雷暴和多种技能同时出现时的重复计算。
